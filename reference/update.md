# Update Item(s)

Update Item(s)

## Usage

``` r
update(values, items)
```

## Arguments

- values:

  a data.frame used to update the items.

- items:

  a data.frame of the items.

## Value

a data.frame.

## Details

The function will drop unmatched id(s) in `values`.

## Examples

``` r
if (FALSE) { # \dontrun{
update(values, items)} # }
```
