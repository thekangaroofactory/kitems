# Item Card

This is a UI / Layout function for the Admin Console

## Usage

``` r
admin_item_card(name, description = NULL)
```

## Arguments

- name:

  the name of the item

- description:

  an optional description

## Value

a div() HTML object

## Examples

``` r
if (FALSE) { # \dontrun{
admin_item_card("date")
} # }
```
