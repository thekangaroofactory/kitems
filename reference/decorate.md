# Decorate Item Columns

Apply mask on attribute names.

## Usage

``` r
decorate(x)
```

## Arguments

- x:

  a data.frame or named object

## Value

A renamed data.frame or object.

## Details

The function makes the column names pretty.

## Examples

``` r
if (FALSE) { # \dontrun{
decorate(x = dm)
} # }
```
