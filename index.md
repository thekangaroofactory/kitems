# kitems

The goal of kitems is to provide a framework to manage tabular *items*
and a set of tools to implement it within R Shiny web applications.

It’s main component is delivered as a Shiny module.

## Installation

The package can be installed from R-universe:

``` r

# Install 'kitems' in R:
install.packages('kitems', repos = c('https://thekangaroofactory.r-universe.dev', 'https://cloud.r-project.org'))
```

## Migration

Version 0.8.x requires a data model migration from previous versions as
well as some modification in your app.

Check this
[article](https://thekangaroofactory.github.io/kitems/articles/migration.html)
to get the detailed procedure.
